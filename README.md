# Finalidad del proyecto:
Este proyecto es una aplicación web desarrollada con VITE + REACT
que permite gestionar los datos de alumnos de manera sencilla.

La app permite:
    - Agregar, editar, eliminar y visualizar información detallada de cada alumno.
    - Navegar entre diferentes vistas utilizando React Router DOM.
    - Manejar eventos en React y actualizar el estado de forma eficiente.
    - Visualizar los alumnos en una lista y acceder a cada detalle de forma individual.

Está organizado en componentes funcionales reutilizables, utilizando rutas dinámicas, redirecciones y eventos personalizados para una mejor experiencia de usuario.
